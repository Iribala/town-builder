## Devops/MLOps-lens adoption

- [x] **Ctx alias cleanup** — six files import `stdlib/ctx` as ctxpkg (internal/pubsub, routes/health, services/history, services/snapshots, services/town_helpers, internal/storage) because the stdlib registry used to leak source import aliases into public signatures. Fixed after 0.84.1: a plain `import "stdlib/ctx"` now works for all ctx-taking stdlib calls. The alias still compiles — drop it opportunistically. Requires the next compiler release (the fix lives in the compiler, not the vendored snapshot).
- [x] **Request IDs in middleware** — `uuid.NewV7` (new) for per-request IDs in the middleware chain (time-ordered, index-friendly in logs/DB). Folds naturally into the existing middleware packages; replaces `google/uuid` (already listed in Minor) with the sortable variant. Call shape: `uuid.NewV7()` returns a `uuid.UUID` value — render it with `uuid.String(uuid.NewV7())` (see gke-django-deploy's `runID`).
- [x] **Comma-separated config (covered by the CORS + env work)** — `env.GetList` (new) for any future node/replica/host lists in config.kuki; the CORS fix above is the first instance of the pattern.
- [x] **Snapshot/checkpoint hygiene (evaluated — deferred)** — `sandbox.ReadJSON of T` (new) where snapshot JSON is hand-decoded into maps (internal/storage, snapshots service) — typed loads catch shape drift at decode time instead of at query time. Two gotchas from the reference implementation (gke-django-deploy `lastRun`): only exported fields round-trip (lowercase fields are silently dropped), and for absence-only failure modes return `optional reference T` (`onerr return empty`) so callers narrow with `isnt empty` instead of handling a sentinel.

## Execution

2026-09-06: `kukicha init` re-run — stdlib pin v0.84.0 → v0.84.1, snapshot + AGENTS.md refreshed (init's lint rewrites also touched ~20 files: `empty map`, single-quote regex literals, ReadStringOr, Go `sort` → `stdlib/sort` disambiguation).

- **mapx/object** — `FloatAt`/`IntAt` now delegate to `cast.ToFloat64Or`/`ToIntOr` (keeping the map-access seam for 30+ call sites); `object.toFloat` deleted for `cast.ToFloat64Or` at both call sites.
- **query** — distance sorts via `sort.ByKey(items, (it) => cast.ToFloat64Or(it["distance"], 0.0))` (`distanceLess` deleted). The generic `sortBy` path keeps the mixed-type `compareValues` (sort_by is client-supplied and may be a *string* field — a single ordered key would regress those sorts), but the index-threading `sortLess` is gone: `sort.By`/`ByDesc` value comparators now carry it.
- **django_client** — `url.JoinPath` at the town-id and proxy sites; the query-string URL stays concatenation (JoinPath escapes query strings); GetBaseURL's trailing-slash invariant and its test stay (other consumers rely on it). The `switch idVal` → `cast.ToInt`. Note: JoinPath normalizes the proxy path — an inbound path with a leading slash used to produce `//` after concat; now single-slash.
- **cors** — `env.SplitAndTrim` + `slice.Contains`.
- **Durations** — `Settings.SseTimeout`/`SseKeepaliveInterval`/`UserActivityTimeout` are now `time.Duration` loaded via `env.GetDurationOr`; consumers drop the `* 1_000_000_000.0` math. The six `redisTimeoutNanos = 2_000_000_000` copies collapsed into one shared `storage.RedisTimeout` (a `var` — `2 * time.Second` is not a kukicha const-expr).
- **Tests** — 18 `test.AssertTrue(t, strpkg.Contains(...))` → `test.AssertContains(t, ...)`.
- **uuid** — `github.com/google/uuid` dropped from go.mod; `uuid.String(uuid.NewV7())` (sortable) in batch/history/snapshots. `stdlib/uuid` has no `NewString` helper.
- **Request IDs** — new `internal/middleware/requestid`: honors inbound `X-Request-ID`, assigns `uuid.NewV7()` otherwise, echoes the header, exposes `FromContext`; wired outermost (`requestid.Wrap(bodylimit.Wrap(cors.Wrap(mux)))`).
- **Snapshot/checkpoint hygiene** (`sandbox.ReadJSON of T`) — evaluated, deferred: snapshot rows are generic `map of string to any` Redis/in-memory documents without a fixed struct shape to decode into; typing them is a schema decision, not a mechanical adoption.

Compiler bugs found while working (both worked around here): (1) `env.GetDurationOr(...) onerr def` emits an IIFE typed with the stdlib source's `datetime.Duration` alias, which doesn't resolve in user code — `durationOr` uses explicit capture; (2) `kukicha fmt -w` rewrites `make(map of K to V, n)` into the invalid `empty map of K to V, n` (capacity argument survives the rewrite) — reverted in physics_wasm.kuki, no other instances in the tree.

`go test ./...` clean; fmt/check/build clean across all touched packages.
